ONLINE SHOPPING BEHAVIOUR ANALYSIS USING WEKA
================================================

Files:
- online_shopping_behaviour.arff : Ready-to-open WEKA dataset (recommended)
- online_shopping_behaviour.csv  : Same dataset in CSV format
- Project_Report.docx            : Editable project report
- WEKA_Steps.txt                 : Step-by-step implementation instructions

IMPORTANT:
This is a synthetic educational dataset (200 records), created for demonstrating
WEKA classification. It is not real customer data. Do not present the results as
real-world business findings. Run the algorithms in your installed WEKA version
and enter the actual output values in the report.
